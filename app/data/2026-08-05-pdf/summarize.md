En este video comparé dos opciones para transformar archivos PDF en Markdown pensando en un caso muy importante para AI: alimentar sistemas o knowledge bases con contenido bien formateado. Yo normalmente usaba el servicio de Cloudflare, pero decidí probar una nueva alternativa open source lanzada por Firecrawl llamada PDF Inspector. Para hacerlo, armé rápidamente un previsualizador y puse ambos a competir con distintos tipos de archivos, desde PDFs densos hasta documentos sencillos, currículums y archivos con muchas tablas.

Mi impresión fue que los dos funcionan razonablemente bien con documentos básicos, pero PDF Inspector me pareció superior en el formateo general del Markdown. Noté que Cloudflare tiende a dividir el contenido página por página y a veces deja textos cortados o menos organizados, mientras que PDF Inspector entrega un Markdown más limpio, más ordenado y con una mejor vista previa. Donde realmente vi una diferencia fuerte fue en el manejo de tablas: Cloudflare prácticamente no logra reconstruirlas bien y muchas veces deja contenido vacío o pierde por completo el formato, mientras que PDF Inspector sí consigue extraerlas de forma mucho más útil. Para mí, eso es clave si luego queremos usar esos archivos en modelos de lenguaje, porque entre mejor venga el Markdown desde el inicio, menos procesamiento extra necesitamos después.

También destaqué que PDF Inspector tiene una ventaja enorme: es gratis y además es una librería open source muy fácil de integrar. Yo vi que se puede usar con Python, Node, Rust e incluso desde el navegador con WebAssembly, lo que da bastante libertad técnica. En cambio, Cloudflare sigue siendo sencillo de usar porque solo requiere llamar a un endpoint con el archivo, el token y el account ID, pero depende de una suscripción. Desde mi perspectiva, si alguien ya usa el ecosistema de Cloudflare puede seguir aprovechándolo, pero si solo necesita convertir PDFs a Markdown, especialmente cuando hay tablas o documentos más complejos, PDF Inspector me parece una opción mucho más atractiva. Yo mismo terminé con la sensación de que podría ahorrarme esa llamada a Cloudflare y pasarme a esta librería para futuros experimentos.
